Under the hood

How AutoPlay works.

There is no complicated service running behind the scenes. The extension reacts directly to the YouTube player.

01

Detect Shorts

The content script checks that the current page is a YouTube Shorts page.

02

Watch the video

AutoPlay attaches to the video's playback lifecycle and waits for it to finish.

03

Advance

When playback ends, it triggers the next navigation through YouTube's interface.

04

Repeat

The process continues on the next Short, giving you hands-free playback.

Get started

Install in a minute.

AutoPlay is distributed as an unpacked extension for development and personal use.

Developer mode

  1. 1 Download or clone the AutoPlay repository.
  2. 2 Open chrome://extensions/.
  3. 3 Enable Developer mode.
  4. 4 Select Load unpacked.
  5. 5 Select the repository directory.
  6. 6 Open YouTube Shorts and start watching.
